# 共享目录账户同步

1. 在 macOS 的 iCloud Drive 或已有 OneDrive / NAS 中准备一个 Quota 文件夹。Windows 使用对应客户端实际可访问的同一文件夹；没有 iCloud 客户端也可以使用 OneDrive。Quota 不创建账号、不猜测目录。
2. 各设备打开「设置 → 跨设备同步 → 选择目录」，选择该同一目录，开启「同步账户展示资料」。Token 活动沿用相同目录。
3. 点击「立即同步账户」。账户后台每 5 分钟合并，与 Token 自动采集开关独立；应用退出时停止。共享文件是否已上传/下载以云盘客户端为准。活动页「立即同步」同时尝试账户合并。

## 安全范围

账户文件位于共享目录的 `quota-accounts-v1/<设备 UUID>.json`。只序列化固定类型字段：账户 UUID、平台、名称、创建时间、同步方式、提醒阈值、手动金额/预算，以及结构化余额、分项金额和订阅额度快照。分项名称由固定枚举生成，订阅套餐名称归一化；不传自由格式供应商文本。

**没有任何密钥类型字段**：不读取系统凭据库，不同步 API Key、AccessKey、管理员密钥、Cookie、Codex token 或账号绑定信息；也不传备注、URL、请求头/请求体、自定义接口解析配置、原始响应、对话正文或源日志。不要在账户名称、设备名称中填写秘密。同步文件包含账户金额等个人资料，请使用仅本人/可信设备可访问的目录，不公开分享。

新设备收到的是展示资料和快照，不具备查询权限。需要查询时在该设备连接账户；原设备的自定义连接字段与系统凭据不被远端覆盖。备份的加密登录信息选项属于用户主动导出，不会被自动同步程序扫描或上传。

## 合并与故障

- 同账户 UUID 的显示资料以最新本机观察到的编辑时间为准；同毫秒冲突按设备 UUID 排序，确定性收敛。独立新增的账户 UUID 不同，不根据相同名称猜测为同一账号。首次同步已有同 UUID 账户时，较晚加入同步的显示资料可能成为最新编辑。
- 余额/订阅快照独立比较查询时间，旧值不覆盖新值，不相加。金额 0 与无数据区分；云端快照不能当成刚查询的实时账单。
- 删除仅影响本机，并在本机同步台账中标记隐藏，避免下一轮重新出现；不删除其他设备账户或任何远端文件。账户 UUID 和隐藏台账不要手动修改。导入同 UUID 的账户可重新启用本机显示。
- 设备时钟应正确；超过当前时间一天的编辑或快照被拒绝。未知字段、跨平台同 ID 冲突、无效格式和超过 4 MB / 1000 账户 / 100 设备文件的输入不合并。同步文件子目录/文件不读取符号链接。
- 本机 `account-sync-state.json` 保存已观察的安全资料版本及隐藏记录，`account-sync-status.json` 保存最后本机合并时间和错误。失败保留本机账户及待重试版本；云盘未下载完成或目录离线时可稍后重试。配置与台账是两个文件，部分写入失败后会重新比较，不保证跨文件事务。

当前共享同步不包含余额历史、应用全局设置、模型资料或登录信息；这些内容仍通过统一备份/导入迁移。上线前的测试使用合成共享目录，不声称已经验证 iCloud / OneDrive 的真实云端传输。
