# Token 活动与跨设备同步

在「Token 活动」点击「立即同步」，首次扫描本机保留的 Codex 和智谱 ZCode 历史。打开 Quota 时默认每五分钟增量采集，可在「同步设置」关闭。

跨设备：在每台设备的「同步设置 → 共享目录」选择各设备都能访问的同一个 OneDrive、网盘同步文件夹或 NAS。目录同步由现有网盘客户端或 NAS 完成；Quota 不创建云账户、不上传登录信息。各设备需运行 Quota 才会采集和交换记录。未选择目录时只在本机统计。

## 数据与口径

- Codex：只读 `CODEX_HOME`（默认 `~/.codex`）下 `sessions`、`archived_sessions` 的 JSONL。按累积 Token 的增量计数；工具按 call ID 去重；分叉继承的历史不重新计数。
- ZCode：只读 `~/.zcode/v2/tasks-index.sqlite` 和 `~/.zcode/cli/db/db.sqlite`，优先采用 `model_usage` / `tool_usage`。旧记录从 message/part 中只选取用量字段，排除已有的现代用量记录。迁移产生的两份数据库按请求 ID、尝试号与工具 call ID 去重。
- 输入包含缓存命中和写入；推理包含在输出中。总量不再叠加这些子项。请求尝试分别记录，因为每次尝试可能产生实际用量。
- 历史范围只覆盖仍保留在本地的记录，无法恢复已删除的会话或厂商未记录的用量。这是用量统计，不代表账单或订阅剩余额度。
- 每台设备有独立 UUID 和可编辑名称；全部设备合并后可以按设备、来源和时间筛选。相同日志被复制到多设备时只保留一笔，确定性归属 UUID 较小的设备，不宣称能够还原原始执行设备。

## 热力图、模型与时间量程

模型按钮和明细中的模型名称可选中该模型，顶部指标、每日热力图、趋势与其他明细都按模型名称精确筛选。模型切换选项保留当前设备、来源及时间范围内的所有型号；不会把相似型号合并。未知品牌使用字母标识，已支持品牌复用账户图标。

热力图按当日总 Token 与当前图内峰值分为四档，零用量使用中性色；点击日期查看输入、输出及缓存子项。支持方向键移动和 Home/End。近 N 天包含今天及首日完整的本地自然日，空日期补零；全部历史可按年份浏览热力图，趋势保留整个历史范围。未来日期不参与当前报表，原始指标仍保留在统计库中。

日量程为折线，周/月为汇总柱图；周一开始一周，月按自然月划分，范围两端可能是不完整周或月。按周期只汇总 Token 字段，不把每日会话数相加伪造唯一会话数。缓存与推理继续作为子项，不叠加到总量。

图表计算与静态组件检查：`node scripts/verify-activity-charts.cjs`、`node scripts/verify-ui-render.cjs`。这些不代替真实浏览器的布局和键盘交互验收。

## 存储与同步协议

`%APPDATA%\Quota\activity.sqlite` 保存指标、增量游标、同步队列及已接收文件记录；`activity-settings.json` 保存日志路径、设备与同步设置；`activity-status.json` 保存最近采集状态。`QUOTA_DATA_DIR` 可用于隔离验证。

共享目录的 `quota-activity-v1/<设备 UUID>/` 保存只包含指标的版本 1 JSON 分片。写入采用临时文件加原子替换；成功写出后才移除队列。重新接收或扫描相同事件不会重复累计。同步内容没有对话正文、工具参数、API Key、Cookie 或登录 Token；会话 ID、模型名称、工具名称、时间及设备名称会随指标同步。共享目录应使用用户自己的访问权限。

验证：`cargo run --release --example activity_checks` 覆盖重复计数、追加、未完整行、截断重读、分叉、双设备、筛选和重复 ZCode 数据库；`--live` 在独立测试目录只读扫描本机来源，不修改原日志和个人 Quota 配置。

官方 ZCode 功能说明：[Usage Statistics](https://zcode.z.ai/cn/docs/usage-stats)。这里展示本地活动，与厂商 Coding Plan 云端额度分别计算。
## DeepSeek Harness 适配（2026-10-04）

在 Token 活动的「同步设置 → 日志位置」选择 Harness 的持久化根目录。未选择时不扫描；不推测默认目录。支持官方 `session.v2.jsonl` 至 `session.v4.jsonl`，以及默认 `.jsonl.zstd` 的拼接压缩帧。每个会话只读取最高编号的代际；未知版本不回退到旧版，不修改或迁移源日志。

仅保存会话标识、时间、模型、Agent 标签、工具名称和用量。顶层 `usage` 优先，否则取嵌入 stream 的最后一个 usage。Harness 的非缓存输入、缓存读、缓存写互斥，三者组成输入总量；推理是输出子项。`llm/retry-started` 分隔计费尝试，同一尝试的后续结算替换旧样本。同步使用结算序号 `revision`，较旧副本不能恢复被修正的旧计数。分叉会话跳过最后一个带 `inherited: true` 的 `session/end-seed` 及之前记录，避免复制历史重复统计。

只采集完整 JSONL 行；压缩流末尾不完整时保留已解出的完整记录，完整帧损坏则报告错误。单个源文件/解压内容上限 256 MB、单行上限 32 MB、最大递归 12 层，不跟随符号链接。较旧的 v0/v1 暂不支持；错误显示在活动页。

依据：[官方持久化格式](https://github.com/deepseek-ai/deepseek-harness/tree/master/packages/session/session-persistence-jsonl)、[官方用量折叠](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/llm/token-meter/src/usage-projection.ts)。验证命令：`cargo run --release --example harness_checks`。

本轮交互更新：来源、模型、明细、量程与趋势指标使用选择框。日/周/月趋势采用通过真实聚合点的三次曲线和淡色面积；曲线控制点限制在相邻点之间，不产生高于两端的过冲，既不是预测，也不修改实际 Token 汇总。图中可悬停选周期、用左右键/Home/End 选点，热力图仍按每日总量。缓存和推理仍为已有总量子项。

### 模型搜索选择（1.0.0500）

模型下拉按厂商分组并支持多关键词搜索，原始 ID 包含命名空间/推理后缀时保持完整，品牌推断仅用于显示。选中摘要和占比基于当前设备、来源及时间范围的 availableModels，而非所有历史；选择只传原始 ID，不合并不同版本。空型号记录包含在全部模型中，不单独伪造 ID。尚未读取的用量不当作零。

## 1.0.0800 日期与明细交互

总量、输入、输出、缓存指标卡可直接切换趋势指标，工具和会话卡跳至对应明细。趋势先于热力图，悬停只预览，点击固定日/周/月并筛选下方明细；方向键移动预览，Enter/空格选择，Esc 清除。热力图点击选择单日，并同步趋势。明细提供模型、工具、Agent、设备页签和清除日期入口。

所选周期边界裁剪到当前时间范围，后端按本地日期筛选原始指标事件，重新计算模型、工具、设备与唯一会话数；不会通过每日会话数相加造成重复。异步响应按筛选条件匹配，切换筛选会清除日期选择。指标卡始终表示顶部整体范围，所选明细总量单独显示。
