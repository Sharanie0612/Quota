# 账户连接与数据迁移

## 小米余额和订阅共用登录

先添加任意一种小米账户并完成官方登录。添加另一种时，在“使用已连接的小米账户”中选择原账户，点击“使用此账户”，保存即可，无需第二次扫码。多账号按账户名称选择；“登录另一个小米账户”用于不同的小米账号。

凭据只在后端和系统凭据库中流转，不返回前端。两张卡片保存同一登录会话；重新连接任一卡片时，更新共用该旧会话的卡片，不更新其他小米账号。删除一张卡片不会删除另一张卡片的凭据。

## 导出到 macOS

- **导出数据**：普通 JSON，包含账户 ID、平台、名称、同步方式、提醒阈值、手动金额、预算、设置、模型资料与官方来源、隐藏模型、余额历史和已采集 Token 活动。无 API Key、Cookie、AccessKey、管理员密钥或 Codex token。不导出账户备注、Base URL/充值 URL、自定义请求及本机采集/同步路径，避免其中的任意秘密进入明文文件。
- **导出加密备份**：包含完整账户配置、系统凭据库中的 API Key / AccessKey / 管理员密钥 / 小米 Cookie、Codex 账户绑定、设置、模型资料、隐藏模型、余额历史和 Token 活动。AES-256-GCM 加密，PBKDF2-HMAC-SHA256 600,000 次派生；密码不落盘。自定义请求中可能存在的秘密也只在加密文件内，不代表这些字段在平时的 config.json 中受到凭据库保护。

Windows 和 macOS 使用同一平台无关 JSON 结构及加密格式。macOS 版本接入相同迁移模块后，密钥通过现有 keyring 后端写入系统钥匙串，无需复制 Windows 凭据库。此 Windows 环境没有执行 macOS 构建或钥匙串实机测试。

Cookie 到新设备后可能失效，届时重新登录一次，并供小米两种卡片共用。ChatGPT 只导入账户资料与绑定，不迁移或刷新 Codex token；需要在新设备登录 Codex 后连接。每台设备保留独立统计 UUID；采集路径、共享目录和飞书授权需在新设备另行设置。

## 选择导入

设置 → 备份与迁移 → 导入数据 / 迁移账户 → 选择文件。加密备份输入原密码，普通 JSON 留空；点击“读取内容”后勾选：

- 具体账户；可全选或只选几个。加密备份可另选是否导入这些账户的登录信息。
- 应用设置。
- 模型资料与隐藏列表。
- 余额历史。
- Token 活动。

点击“导入所选内容”后重新加载。按账户 ID 合并，已有同 ID、同平台账户更新所选资料，不删除其他账户；同 ID 却不同平台时停止。普通 JSON 更新已有账户时保留本机未导出的自定义连接配置与备注。不选登录信息时不读取或修改本机凭据。

模型资料按型号别名和供应商范围匹配更新，隐藏列表合并。选择账户时，余额历史只导入这些账户；历史单独导入时，只合并本机已有账户记录，以时间戳与金额去重，不伪造充值事件。Token 活动按现有事件 ID / revision 协议合并，不重复累计，不导入对话或同步队列。

预览不显示秘密；读取后文件改变时须重新预览。发生写入失败时回滚本次配置、资料、历史和凭据写入；如果回滚失败，明确显示错误，不报告成功。

## 格式兼容

普通导出使用 `format: quota-data-export`、`schemaVersion: 2`，可恢复资料而不含凭据。旧 `schemaVersion: 1` 数据文件和 `quota-activity-sync` 统计文件仍可导入；旧普通导出未保存价格来源时，导入保留价格并撤销缺少来源的“已核实”标记，不猜来源。

加密外层仍为 `magic: QuotaBackup`、`version: 1`；内层迁移载荷升为 `version: 2`，增加 `balanceHistory` 和 `activity`，兼容旧内层 `version: 1`。旧客户端不能读取新内层备份，目标设备需使用 1.0.0900 或接入此模块的版本。

普通 JSON 和加密备份文件均有 256 MB 上限，超过时导出停止，不生成无法导入的文件。统计导出只读取已提交指标，不触碰原始会话日志。自动查询快照不当作当前余额恢复；导入后需刷新，或使用保留的手动余额。
