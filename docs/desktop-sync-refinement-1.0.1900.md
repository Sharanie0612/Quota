# 桌面交互与同步修复 · 1.0.1900

本次沿用尚未发布的 1.0.1900 功能版，不按提交次数重复递增。依赖上一轮 Trae 分类与悬浮窗改动（PR #13）。

## 行为

- 通过官方 Tauri single-instance 插件限制单实例，再次启动只恢复、聚焦原主窗口，保留原页面。
- 悬浮窗移出后 120 毫秒触发收起，待过渡完成再缩小原生窗口；保持面板挂载，避免重复创建和重复展开 IPC。拖动标题区域可移动，松开后按当前位置贴到最近屏幕边缘并保存高度。移动请求按绘制帧合并、串行提交，收起不会丢失位置；减少动态效果偏好仍生效。不宣称在所有硬件上达到固定帧率。
- 隐藏滚动条外观，保留鼠标滚轮、触控板和键盘滚动。
- Trae 保留独立供应商及“Trae 提供 / API 接入 Trae”两个筛选入口。旧同步记录缺少 channel 时，不再覆盖同一模型已知的分类；通道未知的历史数据保持未鉴别，来源设备重新采集后才能补齐，不按模型名猜测。
- 费用同步以包内合法设备 UUID、记录版本和严格字段白名单验证身份，允许云盘生成的重名副本；重复副本不会重复计费。新账期、实付支出、手动汇率保存后立即排队同步，失败不会撤销本机保存。
- 同步面板使用轻量状态查询；“立即同步”并行处理用量、费用和已开启的账户同步，不重新扫描所有源会话。单个状态读取失败不阻断其他模块；账户关联只在有待处理账户时显示，不再藏在双层折叠里。保留设备状态、故障原因、目录更换及存储维护。

## 天梯数据口径

标准价仍是官方标准档非缓存价格。价格排序与图表共用单位、币种校验；缺少可靠汇率时不可换算的价格排在末尾。只有美元模型且汇率不可用时，图表自动使用美元。无可比 Token 价格的分类显示原因并提供模型列表入口；列表只展示当前分类有评测的型号，筛选与比较选项折叠。

新增“已核实优惠”场景，标准价不被覆盖。当前确定性适配 DeepSeek 官方峰谷表：分别解析输入、输出与缓存命中的高峰/闲时价格，精确型号匹配，核对单位、表头、时段规则及 50% 比例。未核实优惠的模型沿用标准价；不自动猜测节假日，不把订阅、批量、代理渠道或其他厂商都乘以 0.5。

依据：[DeepSeek 官方价格](https://api-docs.deepseek.com/quick_start/pricing/)，2026-10-16 读取。官方高峰为 UTC 周一至周五 01:00–04:00、06:00–10:00，中国法定节假日除外；界面显示北京时间 09–12、14–18 点，其他时段为闲时。标准表读取成功但优惠条件变化时停止采用优惠；官网读取失败时保留上次核实记录并标记检查错误。价格检查失败不再把旧价格的来源改成新地址。
