# 1.0.4101 提示、动效与主题字体

本次以已交付的 1.0.4100 为基线，仅迭代修复字段。npm、Cargo、Tauri 及产品展示号均为 1.0.4101。

## 产品行为

- “部分同步未完成”、数据导出和其他非阻断的操作提示显示五秒后淡出，退出过渡为 180ms，支持手动关闭。新结果和用户重试会重新计时。后台重复读取同一条状态沿用原计时，错误详情可在“查看未完成的同步”中展开。
- 普通 Toast 统一五秒，重复内容合并，最多同时显示三条，旧计时器不能关闭新结果。提示颜色跟随当前主题。表单教程、配置损坏、必要的验证及缺失数据说明仍由各业务视图控制。
- 页面切换使用一次入场动画。按钮、开关、导航、侧栏和详情展开采用统一节奏。通过取消、完成、Esc 或点击背景关闭弹窗时，退出动画结束后焦点返回原控件。正在保存的弹窗禁止退出，系统减少动态效果关闭空间移动。
- 统一正文、标题、标签、辅助文字和等宽数字层级。五种主题各自定义字体栈，Claude 保留衬线标题，Codex、VS Code、GitHub、Quota 使用相应的无衬线界面风格。中文采用本机可用字体回退，不联网下载字体。AA 图表内的参考字体保留，外围标题随主题同步。
- 保留 AA 自动更新、Multica 采集、蓝紫 Q 图标、主窗抗锯齿圆角及悬浮窗置顶行为。

## 验证

前端 `typecheck`、`build` 和 `npm run verify` 通过。GNU `cargo check --locked --offline --examples` 通过，编译器报告既有的 `get_api_key` 未使用警告。

`npm run verify:ui` 通过提示与字体、材质、局部光效、光学、用量工作区、速度焦点、显示缩放和悬浮窗时钟八组检查。新增检查覆盖五主题 × 两种明暗模式 × 六页面的 1024px 布局，实测自动关闭、手动关闭、重复提示合并、重试重新计时、弹窗关闭焦点与减少动态效果。

用量工作区用例等待日期弹窗完成退出动画后，再打开下一次日期选择。用例验证了取消、应用和统计金额。

Windows 10 x64 从 1.0.4100 隔离覆盖升级至 1.0.4101，安装向导完成并通过启动检查。向导内嵌程序、NSIS 内的应用程序和安装后的应用程序哈希一致，桌面和开始菜单快捷方式检查通过。原有安装和快捷方式已恢复，8 个现有数据和设置文件的哈希一致。

在与已验收安装程序字节一致的 WebView2 实例中，使用不可用的测试同步目录触发实际同步错误。提示在 5.002 秒后开始淡出，5.183 秒后移除，错误详情仍可展开。主窗和悬浮窗通过五主题 × 两种明暗模式的字体同步检查。弹窗退出中间帧、焦点恢复和系统减少动态效果通过实测。
