# 飞书跨设备统计

## 个人账户

个人账户无法授权当前开放平台应用时，使用文件同步，无需 CLI。

1. Quota 设置 → 飞书跨设备统计同步 → 导出统计同步文件。
2. 打开 https://my.feishu.cn/drive/me/ ，创建“Quota 同步”文件夹，上传文件，保留每个设备的文件。
3. 其他设备下载文件，在设置中选择“导入并合并统计”。可导入多个设备的文件；重复导入不会累加。导入后再次导出包含所有已合并统计，可带回原设备。

格式为 quota-activity-sync / schemaVersion 1。兼容 quota-data-export / schemaVersion 1 中的 activity 部分。只导入用量白名单字段，不覆盖账户、设置、余额、密钥、源日志目录。设备 UUID 不随文件迁移；相同事件按全局 ID 合并。复制到多个设备的相同日志使用字典序最小设备 UUID 作为确定性归属；Token 总量不重复累加，缓存和推理仍是子项。Harness 结算按 revision 更新。

导入先校验所有记录，再用单个 SQLite 事务写入；格式错误时整个导入回滚。上限 256 MB、50 万事件。统计文件包含设备名、会话标识、模型和指标，不包含对话、工具参数、凭据。

## 企业账户可选自动同步

各设备安装官方 @larksuite/cli 并执行 lark-cli auth login --domain drive。能完成开放平台授权的账号可在高级折叠中启用；令牌由 CLI 的系统凭据管理器管理，Quota 不读取令牌。CLI 依赖默认 npm 全局安装路径，未安装时给出可读错误，不自动安装。

同步仅在用户启用后运行，随五分钟自动采集循环执行（关闭自动采集后可点立即同步）。根目录创建或复用“Quota 同步”；多个同名文件夹时中止，避免选错目录。各设备只发布本机采集事件，以 UUID 和 SHA-256 内容哈希命名指标包，每包至多 1000 事件。先下载、核对哈希并合并，再上传未存在的包，失败保留本机记录，下次重试。不使用整目录镜像、不删除远端数据、不上传账户配置或凭据。长期快照有重叠包，但事件去重保证统计不叠加。

个人账户文件同步的网页上传/下载与 API 自动同步是不同能力，不能把文件合并宣称为无人值守云同步。
