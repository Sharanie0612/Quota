# 1.0.3404：应用内毛玻璃与架构整理

2026-11-01。本地修复版本，基于 1.0.3403；用户明确选择应用内毛玻璃并优先稳定。展示号与 npm / Cargo / Tauri 包版本均为 `1.0.3404`。本轮不推送、合并或公开发布。

## 界面调整

- 主窗口恢复不透明 WebView，移除原生 Blur/Acrylic、透明根层、SVG 折射、透镜形变和指针光斑。开启毛玻璃时只模糊应用自身背景；卡片、表单和常规按钮保持实底。
- 前端和 Windows 原生圆角使用同一份 `ui-geometry.json`：浮动窗口/面板16px，普通控件10px，分段内层8px；最大化和分屏按窗口状态使用方角。开关和图表标记保留其专有形状。
- 删除账户页把普通按钮改为透明的旧规则；禁用下拉框不再继承浏览器的整体半透明。配色不再切换文字材质，文字和图表保持稳定。
- 外观选项改为「毛玻璃」，保留旧 `glass` 布尔选择。五种配色、深浅和系统模式共用几何；高对比度临时回退实底，减少动效停用过渡，普通选择使用连续平移。
- 任务窗保持独立透明画布和原生命中区域；保留运行任务、今日/累计 Token、反向展开、设置重置及过期响应保护。

人民币月均换算、支出历史、实际 Token 单价、模型对比、真实配置天梯和每次调用速度散点的计算规则保持兼容。

## 代码整理

外观拆为 `themes.ts` / `preferences.ts` / `index.ts`，分别管理语义配色、合法值和旧修订、共享状态及保存同步。Rust 外观模块只负责校验、原子保存和广播；原生窗口与任务窗继续各自负责几何。

原来的主样式与多层补丁整合为 `src/styles/` 六个职责层，共用按钮和选中动画；样式入口保持一个。窗口类型也由单独的纯解析函数统一处理。

清理10个不再由入口引用的业务模块，包括旧 `LadderView`、`BenchmarkCharts`、`ActivityDetails`、`CacheUsage` 及对应旧计算模块；同时删除液态效果模块、无引用样式和16个已失效的效果/旧页面检查。入口审计未发现剩余的未引用 TS/CSS 文件（不计类型声明）。

组件检查、浏览器预览与安装版检查共用加载器、合成费用、表面断言及预览准备。`npm run verify` / `npm run verify:ui` 作为当前入口，打包脚本与 macOS 工作流同步更新；界面检查结果分目录保存。

账户、账务、同步和资料导入的兼容代码仍有调用，继续保留。历史交付文档只记录当时结果，不把已退役脚本当作当前验收入口。详细边界见 [架构](architecture.md)。
