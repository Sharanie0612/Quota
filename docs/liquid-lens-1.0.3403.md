# 1.0.3403 清透材质与液态交互

2026-10-31 实现，2026-11-01 继续安装验收。展示版本与包版本均为 `1.0.3403`，改善已有液态玻璃的材质与交互表现。

## 改动

用户反馈 1.0.3402 仍不够液态。本轮让材质、轮廓和交互共同呈现透镜感，参考 Apple 对导航层、透镜轮廓及柔性响应的说明：[Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)。保留内容层的清晰结构，继续避免玻璃叠玻璃。

主窗口优先请求清透的原生 Blur，Acrylic 作为兼容回退。浅色底色 Alpha 从 140 降到 116，深色从 152 降到 144，降低底色覆盖；墨色相应加强。仍检查保存修订、系统高对比度及原生边框保护，关闭时清理两种材质。任务窗不使用整窗原生材质，1.0.3402 的窗口线程、非客户区重绘和圆角保护没有改动。

导航、工具栏和选中胶囊使用受圆角裁剪的多方向高光、内侧明暗及底部焦散轮廓。原生材质成功后继续禁用这些控件的网页 `backdrop-filter`，不重复合成半透明背板。主题选择卡去掉实白底，色板保留原配色。

合成对照中发现深色轮廓曾把深色表面当作反光色，出现凹槽观感。现将反光与表面底色分开，深色使用中性亮反射，内容和按压填充保留原有明暗。亮边附近的侧栏收起按钮将键盘焦点收进按钮内，聚焦时使用清晰底面，不让反光冲淡焦点。首轮控件检查有 7 处未达到 3:1，已保留；修正选择器优先级后，五主题四背景的 20 个针对性状态通过，阈值未改。

选中胶囊在约 440 毫秒内拉伸、略微越过目标并回到目标；形变最多延长 14px。连续切换从当时可见位置继续，文字和点击区域不参与形变。按压只改变独立的光层，主操作和危险按钮不叠加亮色，以保留文字对比度。失焦、关闭、减少动效和高对比度均取消正在运行的液态动画，空闲时不运行循环动画。没有新增设置项或页面说明。

原生还原检查又复现了保留键盘焦点时的错位：焦点仍在控件上，但同一表面的指针事件把光斑移到 130px，与目标相差约 700px。浏览器控制输入也复现了 1024/1280px 下约 472/678px 的偏移。现在同一表面保留可见键盘焦点时，光斑优先跟随该控件；鼠标模式仍按指针响应。修正后的八组明暗缩放锚点、两组指针覆盖场景误差均为 0，500 个缩放事件仍合并为一次更新。
