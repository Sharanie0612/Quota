# 小米登录会话复用（1.0.1600）

升级后重新连接一次小米账户，并保存账户。新连接会同时保存控制台查询 Cookie 与官方小米 SSO Cookie；旧版只保存了查询 Cookie，无法凭空恢复未保存的 SSO 会话。按量与订阅卡片可以使用同一次本机登录。

会话只保存在系统凭据管理器，按固定大小分片写入，以避开 Windows 单条凭据长度上限。片段写入并读回后再更新会话索引；更新使用新代际，旧代际在成功提交后清理。普通配置、日志、共享账户文件不包含会话内容；第三方微信 Cookie 不保存。

官方登录窗口继续使用无痕模式，没有 Quota IPC 权限。恢复会话时先打开空白窗口，由后端恢复 Cookie（含域、路径、有效期、Secure、HttpOnly、SameSite），再访问白名单内的官方 HTTPS 页面；恢复失败后仍可在可见登录窗口完成扫码。

余额定期查询沿用设置中的自动刷新周期。服务端返回 Set-Cookie 时更新查询 Cookie 和已保存会话；明确过期时，先在隐藏官方窗口尝试 SSO 恢复。恢复最多 20 秒，同一账户 30 分钟内不反复自动尝试；隐藏窗口不抢焦点，结束后关闭。网络故障不冒充登录过期。应用退出或关闭自动刷新后，不继续定期查询。

小米服务端撤销会话、要求验证或不接受保存的会话时，仍需扫码；本功能不能承诺永久登录。历史 Cookie 没有 expiry 属性，仍通过官方接口验证有效性。真实微信扫码和小米服务端的续期策略需真实账号验收，合成回归不能替代。

加密备份仍保存查询凭据。完整会话保存在本机凭据库独立条目，备份中的会话引用在另一台设备不能恢复 SSO 内容；另一台电脑需要首次官方连接，不自动同步登录权限。
