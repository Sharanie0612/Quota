# Quota 1.0.2800 本地交付

基于已交付的 1.0.2700，任务分支 `codex/feat/model-benchmarks`。展示号与包版本均为 1.0.2800。本次为本机 Windows 功能构建，不代表 GitHub 或 macOS 已发布。

## 本次变化

- AI 模型默认打开 S/A/B/C/D 天梯，整合能力对比、各推理配置的效率曲线、官方价格和来源核对。移除重复的旧天梯侧栏入口，旧快照及兼容命令保留。
- 独立多来源证据和计算模块，固定版本、共同参考群体、五维与平台等权，官网补充受上限约束。计算规则和来源见 [模型测评算法](model-benchmarks.md)。日期、参数尺寸与未识别配置不能模糊合并。
- Token 活动的来源、模型与输入缓存使用环形图，可点击图例筛选；长尾合并为“其他”且总量守恒。旧缓存逐模型明细收进折叠。继续使用原报告，不新增采集或账本；输入缓存、写入和输出推理均不重复相加。
- Quota 默认采用暖灰白、石墨强调色。保留显式选择的其他主题、明暗模式与收起侧栏状态。删除重复口号、页面副标题、模型页营销块和主题说明小字；原账户表单三步教程及必要数据/隐私说明保留。
- 安装器为 720×540 标准向导：顶部标题、平面内容、固定上一步/下一步/取消，保留中英语言、位置、快捷方式、确认、真实阶段进度和完成页。底层仍执行经过验证的 NSIS 安装引擎，退出成功且文件哈希一致后才确认完成。
