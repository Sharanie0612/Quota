# 1.0.3000 本地交付

本版移除模型库及其账户卡片/设置入口。AI 模型页改为人民币价格与公开配置能力坐标，默认近 30 天发布型号，恢复六维雷达对比；保留测评与官方价格来源。

新增输出速度页，记录 Codex 的非推理输出 Token / 客户端输出片段秒数，按模型、时间与设备筛选。测量附于原 Token 记录，支持回填、去重和原目录同步。Token 活动环形图改用蓝、青、紫等区分色，去掉图下图例和明细。Quota 默认主题改为淡蓝白。

评分口径见 [模型天梯](model-benchmarks.md)，速度口径见 [输出速度](output-speed.md)。
