# 1.0.3001 修正

本版修复1.0.3000安装向导的校验误报，并按用户确认调整模型范围。保留输出速度、六维图、环形图简化和淡蓝配色。

## 安装

在外部 `CARGO_TARGET_DIR` 构建时，向导此前嵌入项目内预先复制的程序，主程序则使用Tauri写入NSIS包类型标记后的文件，两者相差3字节。NSIS已复制正确主程序，但向导将安装结果与自身原始哈希比较后报错。

构建入口现在将实际Cargo产物路径传入NSIS，向导和主程序使用同一个、同一阶段的文件。保留主程序与WebView2Loader.dll的完整SHA-256校验，不跳过或屏蔽差异。

## 模型范围

默认改为各厂商当前主力配置，使用最近30天公开更新的测评版本；不再按型号发布日期过滤。主力范围、版本日期及未知日期处理见 [模型天梯](model-benchmarks.md)。数据核实时间不作为新测评日期。
