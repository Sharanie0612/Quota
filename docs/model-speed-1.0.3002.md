# Quota 1.0.3002

本版调整输出速度、天梯尺寸与六维选择交互，保留1.0.3001的测评来源、当前主力范围和严格安装校验。

- Codex输出速度在后台以10秒为目标周期采集，复用活动记录的游标、去重、暂停和同步。显示实际最近采集时间，不以页面轮询冒充采集。
- 新增近1小时视图及10秒至1天的时间粒度，按完成时间分桶，用Token总数/总输出时长显示均值。空档不补零；本地日历分桶。
- 速度页合并控制区，突出平均速度，展示中位数、P95、有效样本和采集状态。曲线按真实页面宽度绘制，减少空白与缩放模糊。
- 天梯移除图内常驻名称，仅保留模型图标；悬停或键盘聚焦显示完整型号、配置、评分和价格。绘图区自适应宽高，可展开，Esc退出。
- 六维对比增加厂商筛选和按厂商分组的型号列表，保留最多三个完整配置与真实分项。

## 验收

本轮 Windows 验证通过：

- `npm run typecheck`、`npm run build`、`cargo check --locked --offline --examples`，以及速度、活动、SSH和压缩同步release examples。
- 速度回归覆盖10秒与按天分桶、按本地日历对齐、加权均值、暂停恢复、快速与完整采集复用游标，不重复累计。
- Edge中检查1024/1360宽度、明暗模式、悬停提示、展开与Esc退出、厂商分组选择、时间粒度切换；五种主题与三种安装向导流程另行检查（演示资料）。
- 打包程序隔离运行，完整采集周期设为900秒，直接观察后台连续三次采集，间隔为 **10.117秒、10.094秒**。没有页面刷新参与；账本仍为2条速度样本、3390 Token。
- 安装包解包后，安装向导与主程序SHA-256完全相同，WebView2Loader与源文件相同；主程序与构建产物仅有Tauri规范的3字节NSIS类型标记差异。
- 在实际安装目录 `D:\Quota` 完成 **1.0.3001 → 1.0.3002** 覆盖升级，现代向导完成页正常。5份既有用户资料文件哈希未变，安装版启动8秒检查与真实WebView页面检查通过。
- 安装版逐条核对77个完整配置、29个当前主力配置、六维图与合成日志速度值120/150/200 tokens/s和2个样本。

10秒为正常运行时的目标读取周期，受任务串行、系统调度及SSH读取耗时影响；完整响应的用量与计时到齐后才记录速度。未进行本轮macOS打包、真实跨设备云端及SSH双机验证，不将本地隔离回归当作这些实机结果。公开评分与价格数据未在本版更改。
