# Quota 1.0.3003

本版重构输出速度的数据读取和整个速度页，修复上一版以轮询频率暗示测速分辨率、全局采集阻塞本机、刷新清空悬停、慢查询互相覆盖和操作繁杂的问题。AI模型评分、天梯和六维数据保持1.0.3002的已验证实现。

## 行为

- 本机以1秒为目标周期增量读取近期文件，独立于SSH和目录同步；原Token账本、游标、去重和同步协议保持兼容。
- 明确显示“最近一次已完成输出”和“时段平均”，进行中的任务只提示等待。没有逐Token计数的日志不宣称具备实时tokens/s。
- 今天、近30分钟、7天、30天与全部范围；均值粒度直接切换，按输出时长加权。按响应完成时间归桶，不把一个长响应均摊成虚构的流式采样。
- 趋势和逐条记录互相核对；模型汇总可点击筛选。去掉主视图的中位数/P95、重复刷新和同步操作。
- 自动更新保留悬停与图表实例。来源异常、暂停、无计时、无用量分别显示，图表空档不补零。
- 单独建立速度与Codex时间索引，避免高频查询全表；读取状态不冒充测得新样本。
