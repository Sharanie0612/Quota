# Quota 1.0.1900 产品界面优化

延续同一待发布 1.0.1900，在无顶部横条窗口和小米会话修复上继续优化，更新到同一个 PR #11。未重复递增版本。

## 界面

- 取消贯穿窗口的侧栏分隔线，右侧使用留白包围的圆角内容面板；侧栏采用轻阴影选中态，保留系统蓝与现有浅深色配色。
- 统一面板、输入框、分段选择及按钮的圆角、尺寸与间距。账户操作改为胶囊按钮，弹窗采用更柔和的背景虚化。
- 设置标题与内容对齐；1024px 下侧栏收窄，费用栏和设置选项可换行。
- 删除账户、活动与设置中的重复说明；移除天梯和我的使用的重复大标题。同步教程和费用统计口径按需展开，账户三步教程、API Key 帮助、隐私边界及费用参考标记保留。

## 修复

1. 我的使用重新进入时恢复已应用的全部历史、自定义日期或月份；非法或损坏的本地偏好回到本月。未应用的日期草稿不替换已保存筛选。
2. 用量采集和账户刷新分别执行，单项失败不阻断另一项；汇总错误，刷新成功的部分仍重新读取。
3. 跨设备同步状态改用设计系统实际存在的颜色类，开启与异常状态正确着色。
4. 恢复内置模型资料前显示确认弹窗，避免一次误点清空本地修改；保存中禁止重复执行。
5. 天梯首次读取失败时停止显示“读取中”，更新失败也不再误称已有数据可用。
