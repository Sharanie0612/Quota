- Harness 支持用户显式选择目录，按官方 v2–v4 日志只读采集指标；涵盖重试、分叉、压缩日志、下降修正与跨设备去重。Token 总量浅色卡为白色，读取、采集与同步失败分别显示可重试状态。
- 模型比较按币种和单位隔离尺度；缺失价格不补零。修复过期请求覆盖筛选结果、弹窗焦点与错误提示遮挡、自定义刷新间隔入口和深色小字对比度。
- 查询失败可直接改用手动余额或订阅额度；百分比校验为 0–100，小米订阅可记录 Credits。配置更新持锁先写盘，写入或 Windows 文件替换失败时保留原内存与配置文件。
