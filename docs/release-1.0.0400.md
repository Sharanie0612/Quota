# Quota 1.0.0400

2026-10-04 · 功能迭代 · 包版本 1.0.400 · 本地测试安装包已生成，未公开发布

以已交付测试的 1.0.0301 为基线。本次包含统一坐标图与日汇率、Token 平滑曲线和新增累计充值补全能力，功能字段从 03 增至 04，修复字段归零，只递增一次。

- 累计充值识别补齐标签/类型差异，MiMo 明确累计字段进入主卡；官方未提供时可在高级设置手动补全金额与币种，卡片标注手动，不改变当前余额。真实零值保留，不把当前充值余额冒充累计充值。
- 模型库移除复制、核价和编辑按钮，仅保留隐藏/恢复；价格核对仍可从天梯进入。
- 天梯默认一张共享人民币价格轴的性能坐标图，每 24 小时检查 ECB 参考汇率；保留原币种、参考日期与同步失败提示，可切换同币种分图。输入/输出/合计成本可选；完整推理版本名称、推理强度筛选与马卡龙配色。
- Token 活动将来源、模型、明细和量程收为选择框。所有量程使用平滑面积曲线，支持总量/输入/输出/缓存指标、悬停和键盘选点；空日补零、各周期真实汇总，不增加预测。
- 微信云同步尚未接入：用户尚未准备微信应用和后端，接入条件与待实现协议记录于 [微信云同步说明](wechat-cloud-sync.md)。当前仍为共享目录同步。

ECB 工作日发布参考数据；休市日保留最近参考日。汇率仅用于价格比较，不是厂商计费汇率。DeepSeek 用量控制台需要登录，本轮无法读取其真实页面；当前使用选择器、指标卡与面积图的产品交互，没有声称复制或验收其登录页面。

实际浏览器视觉复验受访问策略限制，安装器升级未验证；静态 React 渲染与逻辑验证不能替代视觉验收。
