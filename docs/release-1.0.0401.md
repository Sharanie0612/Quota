# Quota 1.0.0401

2026-10-04 · 修复版 · 包版本 1.0.401 · 本地测试安装包已生成，未公开发布

以已交付的 1.0.0400 为基线，仅递增修复字段一次。本轮修复累计消费的遗漏：此前 GLM 已有金额被折叠隐藏，手动记录只补齐了累计充值。

- 余额账户在四字段余额区域下直接显示累计消费，不再藏在更多明细，也不重复显示。
- 官方返回的累计消费类型/标签识别独立于充值。GLM 保留 totalSpendAmount；MiMo 仅在余额响应明确提供 totalSpendAmount/cumulativeSpend/totalConsumption 时读取，未提供保持未知，没有增加或猜测接口。
- 高级设置可按账单补全累计消费和币种；官方值优先，金额为零也显示。负数、非有限数与非金额币种拒绝保存。旧配置缺字段可正常读取。
- 不以充值减余额、单次支付、赠送额度或 Token 数推算消费；此数值为用户账单记录或接口返回累计值，没有宣称跨厂商统计口径相同。

真实个人账户接口及最新视觉复验尚未验证；既有浏览器访问策略限制未绕过。安装器实际升级与解包启动验证分别记录。
