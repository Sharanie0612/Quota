# Quota 1.0.0500

2026-10-04 · 功能迭代 · 包版本 1.0.500 · 本地测试安装包已生成，未公开发布

以已交付的 1.0.0402 为基线，新增模型搜索和分组选择能力，功能字段从 04 增至 05、修复字段归零，仅递增一次。

- Token 模型选择改为可搜索下拉面板，按厂商分组，组内用量排序。Logo、完整模型 ID、Token 和会话数分层显示，不截掉推理版本或命名空间。品牌识别仅用于展示，不改变真实筛选 ID。
- 搜索支持多个关键词（例如 OpenAI high），无结果时提示缩短关键词；未知厂商仍能搜索选择。空型号记录包含在全部模型中，不伪造可独立筛选的模型 ID。
- 选中后显示厂商、完整型号、当前设备/来源/日期范围的 Token、会话数和占比，提供一键回到全部模型。列表按范围读取，切换设备/来源/日期不会误用另一范围的列表；加载未知用量不显示成零。
- 支持方向键打开和选择、Enter 确认、Esc 收起、失焦/点击外部关闭及确认后恢复焦点。中文输入法组词时不因 Enter 误选；搜索无匹配时 Enter 不清除原选择。
- 点击模型明细后回到模型筛选处，图表与指标按原后端模型筛选联动。统计口径、增量、去重和共享目录协议不变。

验证：typecheck、静态 UI 渲染四组、活动图表三组与逻辑 7/7 通过。模型专项检查包括命名空间和推理版本保留、厂商搜索、未知型号恢复、选中摘要、清除入口与加载状态。静态检查不等于真实交互验收；既有浏览器访问策略限制未绕过，最新 1024px/深浅色视觉和实际键盘鼠标交互仍未验证。安装器实际升级未验证，解包启动结果完成后追加。
