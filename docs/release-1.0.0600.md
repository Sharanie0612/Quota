# Quota 1.0.0600

2026-10-04 · 功能迭代 · 包版本 1.0.600 · 本地测试交付，未公开发布

以已交付 1.0.0500 为基线，新增设置数据导出功能，功能字段增至 06、修复字段归零，只递增一次。

设置 → 备份与迁移 → 导出数据，选择保存位置后后台生成带日期时间的 JSON 文件；完成显示账户数、活动记录数和保存位置，取消保存不写文件，失败可重试。导出时显示忙状态，防止同时恢复备份；不会在主线程执行统计序列化。

内容包括账户显示名、平台、手动金额、当前余额和订阅快照、设置、保留的余额历史、模型本机价格/隐藏信息及所有已采集的活动事件和设备。Token 保留原始时间戳、事件 ID、模型和修正 revision，不重新按日汇总或改总量；来源已删除的日志不可能恢复。

不读取系统凭据，不导出自定义 URL、请求头/请求体、账户备注、原始服务商响应、日志路径、扫描游标或同步队列。文件未加密，包含账户名、设备名、会话标识及用量，用户自行保存。导出采用字段白名单，不复制整份 config.json 或 activity.sqlite。模型资料仅导出选择的结构化资料，未复制来源链接和摘要。

格式为 quota-data-export/schemaVersion=1，明确 restorable=false。当前用于查看和保存，不提供导入；既有加密备份仍用于账户/凭据恢复，它不包含 Token 历史。没有宣称新数据文件能够直接恢复完整应用。

统计读取使用 SQLite 只读事务，可读取已提交 WAL，导出不刷新日志、不移除发送队列、不修改源数据库。没有活动库时导出空列表，不创建新库。统计正文超过 256 MB 时中止，保持原目标不变。临时文件写完后原子替换；拒绝保存到应用配置目录，写入失败清理本次临时文件。
