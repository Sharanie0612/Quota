# Quota 1.0.0700

包版本 1.0.700。本地功能迭代，尚未公开发布。

- 进程启动三秒后查询全部账户一次，与后续定时刷新开关独立。
- 天梯加入全部型号能力图、未进入价格图的原因、完整推理强度筛选。同坐标附近圆点展开并用细线指向真实坐标。厂商颜色沿用品牌黑白、蓝、橙、紫色系。
- OpenAI Standard 短上下文表、Kimi 标准档 DocTable 支持精确自动核实：官方 HTTPS、固定列结构、精确模型 ID、币种、百万 Token 单位。页面改版或值无效时不自动更新价格。其他厂商仍检查官网候选并保留人工采用；不宣称所有厂商都已自动核实。
- 每个定价页每轮只抓取一次，最多四个并发。价格检查覆盖未知价格型号；保留最新官方核实快照，失败不退回旧价。
- 设置加入个人账户文件同步：统计文件导出、打开飞书我的空间、导入并合并统计。支持此前 quota-data-export 文件的 activity 部分，事务写入、事件 ID 去重、保留设备归属。不会覆盖账户配置或导入密钥。
- 企业账户可选飞书官方 CLI 自动同步，在根目录查找或创建“Quota 同步”，上传内容哈希命名的指标包；不会删除远端文件。个人账户无法授权该应用，因此文件上传/下载需在飞书网页完成，尚未实现个人账户无人值守同步。

验证：typecheck、Vite build、cargo check、verify-logic 7/7、界面组件与账户/活动逻辑自检通过。activity_checks 与 sync_price_checks 通过，后者还验证了当天官方页面的 38 个 OpenAI 标准型号与 4 个 Kimi 标准型号。1024px 账户表单、天梯与设置在浏览器预览检查；浅色和深色均检查。
