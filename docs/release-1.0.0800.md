# Quota 1.0.0800

2026-10-05 本地测试交付，包版本 `1.0.800`，以已交付 `1.0.0700` 为基线递增一次功能版本。尚未推送或公开发布。

## 用户可见变化

- 天梯自动从 OpenAI、Anthropic、Google、DeepSeek、Kimi、智谱、小米、阿里云、xAI、Meta 官网核实标准价格，取消人工填写与采用表单。排名和型号仍参考 AITier，价格独立获取；排名网站暂不可用时继续检查官方价格。
- 价格详情显示官方来源、核实时间、上下文/地域/时段条件和失败原因。缓存命中与 5min/1h 写入分开。小数保持原精度。无法确认的型号保留上次记录并显示状态，系统自动重试；图像/音频/视频的按次或时长价格不混入百万 Token 比价。
- 十家厂商采用差异更大的固定配色，图例、圆点、能力条和列表标识一致；点击图例可突出一家厂商。颜色最小 CIELAB 距离 33.4，浅色/深色圆点边界对比均至少 3:1。
- Token 活动的指标卡可点击切换趋势，工具/会话卡可跳至明细。趋势悬停预览，点击固定日/周/月，并筛选下方模型、工具、Agent、设备明细；热力图点击与趋势联动。方向键预览、Enter/空格选择、Esc 清除；提供时间预设、分类页签与清除筛选入口。

## 数据与网络

价格解析仅接受明确的表头、单位、币种、档位和精确型号。不同型号或模糊名称不继承价格。Windows 原生公开文档获取作为应用 HTTP 请求失败时的自动备用方式，目的地限制在已登记的官网及小米静态文档资源；不传账户数据或凭据，不执行文档脚本。成功解析后才刷新核实日期。

活动周期按本地日期裁剪到当前整体范围，后端筛选原始指标事件并重新统计唯一会话，避免逐日会话相加重复；缓存/推理仍是输入/输出的子项。异步结果匹配当前筛选，切换筛选清除旧日期选择。
