# Quota 1.0.0801

2026-10-05 本地修复交付，包版本 `1.0.801`，以已交付 `1.0.0800` 为基线递增一次修复版本。尚未推送或公开发布。

## 修复

- 小米订阅及按量账户的登录窗口允许跳转到微信官方授权域名 `open.weixin.qq.com`，修复原域名限制拦截微信登录的问题。
- 授权弹窗转为在原隔离窗口中异步导航，保持同一 Cookie 会话，避免在 WebView2 回调内同步导航造成卡住。
- 仅允许指定官方 HTTPS 域名；登录窗口仍无 Quota 命令权限，Cookie 仍由后端写入 Windows 凭据管理器。
