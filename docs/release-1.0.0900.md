# Quota 1.0.0900

2026-10-05 本地功能交付，包版本 `1.0.900`，以已交付 `1.0.0801` 为基线递增一次功能版本，修复字段归零。功能代码尚未同步远程，未公开发布；文档单独更新不代表代码或安装包已发布。

## 变化

- 小米按量和订阅账户可选择“使用已连接的小米账户”，一次官方登录用于两张卡片；重新连接任一卡片时，更新共用旧会话的卡片，不影响其他小米账号。
- 普通 JSON 数据导出包含可恢复账户资料，补齐预算与模型来源、说明及能力字段；支持 Windows / macOS 使用同一格式。自定义连接信息和密钥使用加密备份迁移。
- 加密备份新增余额历史和已采集 Token 活动，完整保存账户配置、设置、模型资料及系统凭据库内容；不导出 Codex token、原始会话、采集路径或同步队列。
- 导入前读取内容，选择具体账户、是否导入登录信息、应用设置、模型资料、余额历史、Token 活动。按 ID 合并，其他账户与未选内容保留。活动与余额历史去重；文件改变须重新预览，失败回滚本次配置和凭据写入。
- 支持旧普通导出和旧加密备份。旧普通模型导出缺少官方来源时，保留价格并撤销“已核实”，不猜来源。

详细用法及跨平台边界见 [数据迁移](data-migration.md)。
