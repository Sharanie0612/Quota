# Quota 1.0.1001 · 订阅账户同步修复

日期：2026-10-07。以已交付 1.0.1000 为基线，仅修复 Bug，展示号与包版本均为 `1.0.1001`。

小米订阅和 ChatGPT 表单支持百分比额度，但共享账户校验遗漏 `%`，导致正常订阅账户阻断整个账户列表同步。修复后自动订阅未填写备用额度、手动额度以及百分比余额快照均可同步；保留空值与零的区别，百分比限于 0–100，不放宽充值/消费币种或凭据字段限制。共享协议保持版本 1，使用百分比的设备需要更新应用。

验证使用合成双设备目录，不读取凭据、不向个人云盘写入。具体检查结果随本次交付说明提供；真实 iCloud 双机传输和覆盖安装升级不由合成检查替代。

已通过 TypeScript 类型检查、前端生产构建、`cargo check --examples`、7/7 逻辑自检，以及 `cargo run --release --example account_sync_checks`。新增检查覆盖小米/ChatGPT 自动订阅空额度、手动百分比 0/65/100、百分比快照、重复同步，以及越界百分比和充值/消费非法单位拒绝；原有本机连接保留、隐私白名单、旧快照保护和非法设备标识检查继续通过。
