# 1.0.1401：账户共享同步重复项修复

两台设备分别添加同一平台账户时，原实现只按随机账户 UUID 合并，导致同一账号形成多个卡片并被旧设备文件继续传播。删除发生在首次同步之前时，也没有立即保存隐藏标记。

修复后，同平台的新同步 UUID 先等待确认，不自动新增总览卡片。在账户总览和设置中可将现有重复项或待确认项关联到要保留的本机账户，也可明确保留为独立账户。关联映射和删除标记立即持久保存，重启与旧共享文件不再恢复关联掉的卡片。保留选中账户的本机 UUID、连接配置与登录，原账户凭据和历史仍留在本机；余额按最新时间选择，不相加。

两台设备均需升级并分别确认一次关联。共享文件仍为 v1 白名单格式，不新增凭据字段；未自动删除个人账户或共享文件。本轮提供 Windows 修复包，macOS 修复包尚未构建。

验证通过：TypeScript、Vite、cargo check、7/7 逻辑自检、组件渲染与图表回归，以及实际 Rust account_sync_checks example。后者覆盖二十轮双设备交换、不同创建日期与本机连接、最新快照不相加、重启、首次同步前删除、关联项删除、旧文件回流及真实多账号保留。1024px Edge 合成数据预览验证关联后卡片消失、独立账户确认、设置、账户表单和模型天梯。

Windows 安装包为 src-tauri/target/release/bundle/nsis/Quota_1.0.1401_x64-setup.exe，3,114,613 字节。包内版本、WebView2Loader.dll 与源文件哈希及隔离配置启动 8 秒验证通过。本机现有 D:\Quota 安装保持原状，实际覆盖升级未验证。证据分别位于 src-tauri/target/qa-1401-20261009-004002/evidence.json 和 src-tauri/target/qa-1401-ui/evidence.json。真实 iCloud / OneDrive 云端传输及 macOS 安装仍需对应设备验证。

后续更正：1.0.1401 未将原 UUID 的凭据继承到保留 UUID，可能造成关联后显示未连接；1.0.1402 增加本机自动恢复及凭据继承，并移除逐条关联选择。
