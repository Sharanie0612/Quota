# 1.0.1402：关联凭据恢复与同步交互修复

1.0.1401 在关联重复账户时移除了原账户卡片，却未继承原 UUID 的本机凭据，导致保留账户显示未连接。原凭据仍留在系统凭据管理器。本版在启动及同步前按本机已确认关联自动恢复；关联操作先写入并回读核验凭据，再保存账户与关联记录，原凭据保留。目标已有不同登录时不会覆盖或拼接凭据。

同平台、同连接配置且具有相同本机登录的重复账户自动归并；无法确认身份的远端同平台账户不重复加入总览。总览移除逐条关联选择，设置中仅保留默认折叠的额外远端账户入口。不同登录和明确独立账户保持分离。共享文件不包含凭据、凭据指纹或连接配置。

编辑账户显示已保存密钥提示，输入框为空表示保持原值。小米高级设置同样提示，避免把不回显秘密误认为密钥丢失。
