# 1.0.1500：同步空间、界面动效与模型使用价格

共享 Token 数据原先持续写入未压缩 JSON，旧文件永久积累。本版新包使用 Zstandard 无损压缩，同一待同步事件的多个更新只保留一个队列项。在设置中显示共享统计文件大小，可逐包验证后压缩本机旧文件；原始日期、Token 子项、模型、工具和会话统计保留。全部同步设备需升级后再优化旧包，旧版不能读取新压缩包。

侧栏与分段控件的选中背景按真实标签尺寸滑动，页面和账户卡片依次进入，弹窗使用缓动缩放，按钮增加按压反馈。跟随系统「减少动态效果」设置，不引入动画依赖。

小米官方隔离登录窗口完成登录后自动连接，显示等待、网络错误、取消与成功状态。验证仅使用一个有时限的官方认证请求，套餐是否有效与账号登录分开；取消/重新登录使旧检测失效。保留微信 OAuth 域名白名单、远端页面无 Quota IPC 权限、Cookie 仅后端与系统凭据管理器流转。真实扫码与服务端会话过期行为仍需用户账号实测。

Token 活动下方新增「模型使用价格」，展示模型/厂商用量、费用与每百万 Token 综合单价。精确匹配已核实资料，缓存命中与写入单独计费，推理不重复计入；缺价不猜、零价可计算。支持本机自定义使用费率及按设备、来源、日期范围保存的实付账单，人民币/美元分别汇总。订阅默认按 API 等值估算，与实际账单明确区分。

展示版本与 npm/Cargo/Tauri 包版本均为 `1.0.1500`，基于最近本地交付 `1.0.1402` 递增一个功能迭代。
