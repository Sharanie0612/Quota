# Quota 1.0.1502

修复 Windows 安装包继承构建目录低完整性标签造成的 NSIS 临时文件写入错误，以及安装器返回成功但没有覆盖原安装文件的问题。

标准 build/bundle 在 NSIS 生成后仅将最终安装 EXE 设为普通中完整性文件，保留原来的账户数据、升级和卸载逻辑。安装包仍是单个标准 NSIS EXE，不需要 ZIP 启动器，不修改系统 TEMP、目录 ACL 或防病毒设置。标签修复失败时，构建失败并归档失败产物，防止误交付。

包版本与展示号均为 1.0.1502。已验证原系统 TEMP 下用户目录首次安装、原 D:\Quota 路径升级、实际版本和卸载登记，两个安装目录的隔离启动检查均通过。前端类型检查、构建、Rust cargo check、7/7 纯逻辑验证通过；Defender 定向扫描未发现威胁。安装包未签名，SmartScreen 未知应用提示仍可能出现。
