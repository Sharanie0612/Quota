# Quota 1.0.1504

修复从 1.0.1401 / 1.0.1402 升级到 1.0.1503 后，设置页提示“账户同步格式无效，未覆盖本机数据”、账户同步整体停止的问题。

1.0.1503 的本机台账类型只接受 records 和 hidden，而此前修复版已写入 pending、independent 和 links。由于严格校验未知字段，已有台账被拒绝。此版将先前遗漏的账户同步修复定向整合到最新源码，保留 Trae 用量与一键打包入口。

升级直接读取原台账；更早格式缺失的新字段使用默认值。保留账户 UUID、关联、删除/隐藏、待确认项与独立账户决定，无需删除文件或重新添加账户。同平台、同本机登录的重复卡片自动整理，已确认关联中的失联凭据仅在本机凭据库内补齐；不同登录不会覆盖或混合。共享文件仍使用 v1 白名单，不包含凭据、凭据散列或本机关联映射，未知字段与无效记录继续拒绝。

设置页订阅同步完成事件，后台恢复成功后会刷新合并时间并清除旧错误；额外远端账户入口默认折叠，用户可明确选择显示独立账户。

包版本和展示号均为 1.0.1504，仅修复问题，修复字段递增一次。

## 回归检查

- 用旧版 1.0.1503 EXE、空账户、关闭自动采集的合成扩展台账，复现相同错误。
- account_sync_checks：双设备交换、重复 UUID、删除回流、重启、独立账户、百分比额度和安全白名单通过。
- account_connection_checks：内存凭据库验证凭据继承、失联恢复、写入失败保护、不同登录、AccessKey 成对保护及相同 AccessKey 下其他凭据冲突的保护通过。
- account_sync_migration_checks：早期/扩展台账升级、保留关联/隐藏/待确认/独立决定、关联远端快照、重复交换、重启及无效输入保护通过。隐藏等字段按集合比较，不依赖序列顺序。
- TypeScript 与 examples 类型检查通过。浏览器验证后台/手动同步清除旧错误，额外账户显示、极简表单和天梯在 1024px 下无横向页面溢出；没有浏览器异常。

浏览器证据位于 src-tauri/target/qa-1504-ui。云盘验证使用合成共享目录，不能等同于两台真实设备的云端上传/下载验证。

一键打包入口 `npm run package:windows` 已执行，TypeScript、Vite、Cargo、7/7 逻辑自检和 UI 渲染检查通过。安装包包含匹配源文件的 WebView2Loader.dll，EXE 产品版本为 1.0.1504，安装包强制完整性级别为 Medium。
