# 1.0.1600 本地费用迭代快照：混合版本同步兼容与厂商实际使用价格

用户确认 1.0.1500 压缩同步报错，同时仍有旧版设备。旧版不能读取 `.json.zst`。本版通过设备能力声明自动判断：存在未确认压缩读取能力的设备时，逐包恢复本机已压缩历史的 JSON 兼容副本，压缩原包保留，新数据也提供兼容副本；不改写其他设备目录。全部设备升级到本版并各同步一次后，停止生成兼容副本，可在设置中无损校验并优化旧包。兼容期同时保存两种格式，会暂时增加空间。未知能力不等于已经证明该设备版本老旧。

同步逐包隔离损坏、未下载完成和超过上限的文件，继续合并其他有效包；异常包不记录成功回执，下次重试。回执使用解压后的内容指纹，旧 JSON 同名更新也能被读取。设置新增「重新读取共享数据」，只重建接收索引，原有统计保留并按事件 ID 去重。

价格页按用户确认的费用口径改为「实际订阅费 + 按量实际消费」除以对应周期已采集 Token，按厂商展示，展开查看模型用量。仅费用覆盖日期进入分母；筛选截断订阅期时提示查看完整周期，不把整期费用除以几天用量。人民币和美元分别使用对应费用周期的用量，不做汇率换算。年付使用整年实付，进行中周期使用全额订阅费与截至当前已有用量，均价随使用变化。

可选择有来源、地区、周期、核实日期的公开套餐，优惠、税费、旧套餐及续费金额可改成实付。展示接口已有的累计充值/消费，今后保存计数变化；旧余额上涨/下降仅供核对，不作为确认充值或消费流水。没有历史计数时保持未知，不凭累计充值推算本期支出。原 `usage-prices.json` 保留，新的周期支出与计数在 `vendor-costs.json` 仅本机保存。

公开套餐于 2026-10-14 核实：[ChatGPT](https://learn.chatgpt.com/docs/pricing)、[MiMo 官方订阅文档](https://mimo.mi.com/static/docs/tokenplan/Token%20Plan/subscription.md)、[Kimi 新会员价格](https://www.kimi.com/help/membership/membership-pricing)、[GLM Coding 国内价格](https://zcode.z.ai/cn)。套餐费覆盖整个订阅服务，不声称是逐型号账单；中转日志不能自动证明支付对象。

展示号及 npm/Cargo/Tauri 包版本为 `1.0.1600`，在本地交付 1.0.1500 上递增一次功能迭代；本轮包含价格页调整与同步修复。
