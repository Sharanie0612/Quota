# 1.0.1700：我的使用与跨设备同步简化

「模型使用价格」改为「我的使用」，移到侧栏账户总览下方。厂商列表保留，展开查看模型用量和费用，增加搜索。所有本页期间用量、全局历史和费用覆盖用量都排除 `source=trae`；Token 活动、共享文件及原始历史仍保留 Trae，不删除记录。

时间选择支持本月、上月、近 30 天、全部历史和自定义起止日。自定义日期输入完成后点击「应用日期」，选择记住到下次打开；保存费用保持当前筛选。顶部同时显示所选期间 Token、全部历史 Token/会话、人民币费用参考和每百万 Token 参考，厂商搜索不改变全局汇总。

完整账期仍使用整期已记录费用；任意日期截取账期时按自然日分摊订阅及按量费用。由于没有逐日账单，部分周期结果明确标为分摊参考，不能称逐日实付。均价仍以费用覆盖用量作分母；未记录费用不等于免费，原始费用可从「查看账期」核对，缓存/推理不重复加到总量。

美元参考汇率按用户确认的口径：每个月固定采用上月末最后一个 ECB USD/CNY 可用报价（以相同日期的 EUR/CNY 除以 EUR/USD），跨月分别折算。保存后不因当天刷新改变，可手动设定参考或恢复官方参考；原始美元金额保留，缺率显示待补充，不能当作零。月度记录在本机 `monthly-usage-fx.json`，与费用一样暂不纳入原备份/共享协议。来源：[ECB 官方参考汇率和历史表](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html)。数据只作为比较参考，不声称是实际换汇价。

跨设备同步集中到设置顶部一个入口。未开启时三步说明，开启后显示文件夹、已发现设备与本机上次检查，一个「立即同步」同时处理用量和已启用的账户资料。旧版兼容自动处理；更换/停止、同步账户开关、漏同步修复和空间优化收进高级选项。Token 活动只保留本机采集设置，跨设备按钮打开统一设置，不再出现第二套目录配置。登录凭据不跨设备上传；本机处理成功不等于云盘已传输完成。

展示号与 npm/Cargo/Tauri 包版本为 `1.0.1700`，在本地交付 1.0.1600 上递增一次功能迭代。
