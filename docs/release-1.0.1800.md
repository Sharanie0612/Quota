# 1.0.1800：月度使用与独立订阅账期

「我的使用」默认按自然月统计，支持年月选择、上一个月 / 下一个月和回到本月；全部历史与自定义日期仍可查看。所选月份的用量、分摊费用和月度汇率一起更新，原币支出不变，缺少费用或汇率仍显示待补充。

新增独立「订阅与账期」入口，查看所有已记录账期，按厂商及进行中、未开始、已结束筛选。可单独调整订阅开始、结束时间与整期实付费用；修改账期不改变统计月份。后端一次性替换旧记录，检测过期编辑、重叠及目标冲突，失败保留原文件。跨月与年付按自然日分摊，按量费用延续参考说明，不伪造逐日账单。

卡片、表单和弹窗统一增大圆角，补充入场、悬停、按压、展开和加载反馈；跟随系统减少动态效果偏好，沿用现有浅色、深色设计变量。

展示号和 npm / Cargo / Tauri 根包版本统一为 `1.0.1800`，以本地交付 `1.0.1700` 递增一次功能迭代。2026-10-14 的安装包基于 `9171e27` 和当时的本地功能改动构建；2026-10-15 合入远程 `main` 后重新构建，保持同一未发布功能版本。

2026-10-15 在独立分支 `codex/feat/monthly-usage-1.0.1800` 中合入远程 `main` 的 `d120d6e`，继续使用 PR #9。保留共享账户关联、旧台账迁移、小米安全会话与 Trae 通道实现；月度费用读取补充到新同步台账，自动登录验证继续保存轮换后的 Cookie 与安全会话。保留 Token 活动的 Trae 采集与通道筛选，「我的使用」仍完整排除 Trae。跨设备同步使用统一设置入口，账户关联操作保留在高级选项。
