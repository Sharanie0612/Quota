# 1.0.1800：月度使用与独立订阅账期

「我的使用」默认按自然月统计，支持年月选择、上一个月 / 下一个月和回到本月；全部历史与自定义日期仍可查看。所选月份的用量、分摊费用和月度汇率一起更新，原币支出不变，缺少费用或汇率仍显示待补充。

新增独立「订阅与账期」入口，查看所有已记录账期，按厂商及进行中、未开始、已结束筛选。可单独调整订阅开始、结束时间与整期实付费用；修改账期不改变统计月份。后端一次性替换旧记录，检测过期编辑、重叠及目标冲突，失败保留原文件。跨月与年付按自然日分摊，按量费用延续参考说明，不伪造逐日账单。

卡片、表单和弹窗统一增大圆角，补充入场、悬停、按压、展开和加载反馈；跟随系统减少动态效果偏好，沿用现有浅色、深色设计变量。

展示号和 npm / Cargo / Tauri 根包版本统一为 `1.0.1800`，以本地交付 `1.0.1700` 递增一次功能迭代。安装包基于 `9171e27` 和当时的本地功能改动构建。

2026-10-15 按用户要求将安装包对应源码保存到独立分支 `codex/feat/monthly-usage-1.0.1800`，通过草稿 PR 提交到远程。远程 `main` 已有另一组共享账户及小米会话改动，本次保持其内容不变；此源码快照需解决与 `main` 的整合问题并补齐覆盖升级验收后再合并。安装包上传为 `1.0.1800` 草稿 Release，不创建或改写已发布标签。
