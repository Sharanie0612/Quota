# 主机 SSH Token 采集 · 1.0.2100

展示号与 npm / Cargo / Tauri 包版本统一为 `1.0.2100`，以本机已安装的 `1.0.2000` 为功能迭代基线。本次交付主机 Quota 的完整 Windows 安装包，SSH 采集直接集成在 Token 活动中。

## 使用

在 Windows 主机的「Token 活动 → 采集设置」填写已有的 OpenSSH 主机别名，再点击「保存并同步」。Ubuntu 无需安装 Quota；需有 Python 3.7 或更新版本，且该别名已能通过主机上的 OpenSSH 免交互连接。保持自动采集开启即可持续读取新增用量和分批补采历史。

远程目录默认使用登录 shell 中的 `CODEX_HOME`，未设置时使用 `~/.codex`；自定义位置可展开「远程日志位置」填写 Ubuntu 绝对路径。留空主机别名并保存可停止远程采集；当前支持一个别名。

## 行为与隐私

- 本机采集和远程采集共用既有 Token 账本、增量解析、事件去重及云盘同步。远程设备单独显示，重复连接、复制日志或切换别名不会重复累计同一事件。
- SSH 复用本机现有配置、密钥和已信任的主机密钥，不自动接受新主机密钥，不保存密码或私钥。
- 远程仅返回会话标识、模型、时间、工具名称和 Token 用量等白名单指标，不返回聊天正文、提示词、工具参数、认证文件或环境变量，不在 Ubuntu 写入脚本或账本。
- 历史分批读取，失败文件保留进度并重试。SSH 本轮超过 25 秒会停止；本机已采集用量保留。
- Token 活动持续显示采集不完整和失败详情；本机单个损坏或锁定会话不会阻断其他会话，配置的 Codex 目录不存在或没有日志时会明确提示。

完整统计与协议见 [Token 活动说明](activity-stats.md)。
