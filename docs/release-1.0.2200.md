# SSH 主机自动识别 · 1.0.2200

基于主机已交付的 `1.0.2100` 增加自动识别，展示号与 npm / Cargo / Tauri 包版本均为 `1.0.2200`。

打开「Token 活动 → 采集设置」即可识别本机 OpenSSH 配置：只有一个主机时自动填入，多个主机下拉选择；可重新识别或切换手动填写。自动识别只改变当前草稿，保存后才开始 SSH 采集。已配置的主机、正在编辑的值和已保存的关闭选择保持不变。

读取用户与系统 SSH 配置，支持字面量 Host、多个别名、大小写去重、否定模式和普通 Include 通配符、引号、空格及等号。静态识别不运行 SSH，不执行配置中的命令，不读取私钥，也不连接识别结果中的设备；不猜测泛匹配主机或从 known_hosts 推断登录方式。仅保存在 Codex 内部而未写入 OpenSSH 配置的连接需手动填写。

大文件、循环或层级过深的 Include、动态路径、无法读取的配置会受到限制并提示原因；其余结果与手动入口保留。详情见 [Token 活动说明](activity-stats.md)。
