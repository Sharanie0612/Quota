# SSH 设备选择 · 1.0.2300

在「Token 活动 → 采集设置 → SSH 设备」点击「识别设备」，勾选需要纳入统计的设备，保存后生效。新识别的设备默认不勾选，允许全部不选；同一远程用户和 Codex 目录的多个 SSH 别名按稳定设备 ID 合并。未写入本机 SSH 配置的连接可手动添加别名及远程目录。

打开设置只读本机配置；点击识别才连接候选主机，仅读取设备标识，不扫描会话。只有已勾选并保存的设备会采集 Token 和工具指标。离线或认证失败按连接显示错误，保留原有选择；别名指向另一设备时不会继承原设备的勾选。设备标识依据机器、远程用户及真实数据目录，克隆虚拟机应使用各自的机器标识。

取消勾选后，该设备停止采集，已有用量退出 Token 活动、我的使用（含实际价格分母）和悬浮窗汇总；原始指标、游标和同步记录保留，重新勾选即可恢复。统计选择属于这台 Quota 主机，不传播到其他 Quota 客户端。复制日志仍遵守全局去重和确定性设备归属，无法还原原始执行设备。

原单主机配置按已启用的连接迁移，空设备列表明确表示全部关闭，不回退开启旧主机。旧连接首次识别或采集后绑定设备 ID。识别每次最多 32 个连接、并发 4 个，每连接最多 10 秒；采集仍按设备最多 25 秒、并发 4 个，其余适配器和数据格式沿用上一版本。

本版不保存 SSH 密码、私钥或 Codex 登录信息，复用已有 OpenSSH 配置及受信任主机密钥。识别和采集阶段实际调用 SSH 时，OpenSSH 会使用配置中的连接命令；静态发现配置不会执行这些命令。Ubuntu 无需安装 Quota，仍需 Python 3.7+ 和免交互 SSH。
