# Quota 1.0.2900 综合与场景天梯

用户选择“通用综合，同时提供编程、推理、Agent 等分榜”。本轮以 1.0.2801 为基线，新增独立 Epoch 公共数据适配、难度校准场景计算和原始平台对照。分支 `codex/feat/scenario-evaluation`，展示号与包版本均为 1.0.2900。

## 本轮数据和计算

- Epoch 当前公开数据：270 个综合型号、59 项校准、3790 条配置记录；排除 209 个数值冲突组合。
- 通用综合保留发布的 ECI 和 90% 区间，不称为同预算测量；场景按同一配置的原始记录、来源基线与公开难度/斜率求最小平方误差。
- 编程 27、推理 178、Agent 30、知识 116 款；至少两项可比较测评才排名，缺少足够数据的型号仍可查看原始平台记录。
- AA 37、LiveBench 31 款原始平台对照保留；不能将三种尺度的综合值直接平均。
- 场景页签直接展示，默认前 24 款可展开全量；对比图显示综合与各场景，详情显示原始成绩、基线校准、难度、配置及来源。

完整公式、选择规则、版本和限制见 [计算说明](model-benchmarks.md)。场景指数是 Quota 的派生结果，来源 ECI 与其 90% 区间保持原值；逐项留出范围不冒充置信区间。

## 验证

独立 Python 参考实现与 Rust 对账：270 个综合值、351 个场景值及既有 35 个原始榜单黄金预期全部通过。另有已知能力恢复、0/1 饱和、缺失、完整配置、重复与原始 AA 指数检查。

`npm run package:windows` 成功，TypeScript、构建、Rust 类型检查、纯逻辑 7/7、价格目录、测评/占比、设备来源、组件渲染及悬浮窗回归通过。`cargo check --examples --locked` 通过，只有既有 `get_api_key` 未使用警告；未使用本机不可运行的 `cargo test`。

最终 release example 实际读取 AA、LiveBench、Epoch 三家当前来源，656 个参考值通过；本机整套榜单计算实测为 78ms，该数字仅代表本次主机和快照。

浏览器验收覆盖 1024px 明暗模式、七张榜单全量分数/名次/配置/区间、分页、逐条原始成绩与基线换算、五场景对比、详情、离线/空状态、主题、侧栏和安装向导。修正了对比控件遮挡区间，并增加卡片几何检查；六个主页面及账户表单、SSH 分类和窗口状态回归通过。预览账户与活动是模拟数据。

安装器实际将 `D:\Quota\quota.exe` 从 **1.0.2801 覆盖升级至 1.0.2900**。安装向导、WebView、引擎和完成页通过；安装 payload 与解包 exe、WebView2Loader 哈希一致，**6 个既有个人数据文件哈希未变**。

随后使用安装目录的 exe，在空账户、关闭采集和同步的隔离目录中，验证启动、原生悬浮窗与五种窗口状态；真实 WebView 展开七榜共 **689 行**，逐条核对显示分数、名次、完整配置和置信/敏感性范围，全部通过，另与独立参考及黄金预期交叉核对。正常安装版进程已恢复。
