# 1.0.1200 界面迭代

天梯统一为图表、列表、能力图三个视图，取消分图入口及图表/列表中的对比控件。能力图最多叠加三个精确评测型号，六轴为综合、编程、数学、科学、推理、智能体。沿用 AITier 各榜单的相对评分；缺失维度留空、不补零、不用其他维度代替。

图表和列表点击模型可查看小卡片：六维评分、标准输入/缓存命中/输出价格与推出时间。价格沿用官方核实资料。推出日期只读取 AITier `initialModels.releaseDate` 的明确日期并按精确模型 ID 匹配；本轮补齐 71 个型号，来源 https://aitier.net/zh ，读取日期 2026-10-07。没有日期显示暂无资料，不拿排名更新时间充当发布日期。旧缓存可从内置同 ID 日期补齐。

GLM 使用固定版本 Lobe Icons 的 Z AI 标识；账户、模型库、天梯与活动共用本地品牌资源。天梯标记由 18px 缩至 12px，不改变坐标或价格。图表仅保留一个价格坐标系，可切换币种；汇率不可用时仅显示所选原币种，并保留其他型号的可选入口。

Token 活动交互与统计口径见 [activity-stats.md](activity-stats.md)。常规说明收进统计口径折叠，价格来源与实际失败原因仍可查看。

验证：前端类型检查、生产构建、`cargo check --examples -j 1`、7/7 纯逻辑检查、天梯坐标、组件渲染与活动图表回归通过。`activity_checks` 实际运行通过，新增厂商汇总、小时总量守恒与会话去重断言。1024px mock 浏览器检查了账户极简表单、模型库、天梯三个视图、模型卡片、设置、数字切换、厂商筛选和单日小时趋势；深色测试页检查了 GLM 图标与能力卡片。浏览器使用合成数据，不代表个人账号接口验证。
