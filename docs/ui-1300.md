# 1.0.1300 小时趋势与天梯留白

Token 趋势增加明确的总览与按日区分：总览展示历史每天汇总，按日直接选择最近有记录的日期并展示 00–23 时曲线，可在日期控件切换、在小时控件查看数值并返回总览。点击总览某一天及热力图仍进入该日小时趋势。按周和按月保持原有汇总口径。使用现有后端小时统计，不将每日总量均分成小时；演示数据为保持总量守恒的合成小时波动。

天梯绘图区纵向从 288 增至 456 个坐标单位，容器高度随图表比例增长，去掉最大高度压缩。价格和评分映射公式、型号坐标真实性、标记尺寸保持一致。筛选、图例、列表行、能力图与未入图型号入口增加间距。

类型检查、生产构建、cargo check、7/7 纯逻辑检查、活动图表、天梯坐标及组件渲染回归通过。1024px 合成数据浏览器核对按日入口、日期切换、24 小时选择、返回总览、周月标签，以及天梯图表、列表、能力图间距。
