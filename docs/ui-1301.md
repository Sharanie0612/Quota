# 1.0.1301 天梯自适应区间

坐标区间根据当前可绘制模型的价格和评分自动计算，搜索、能力分类、推理强度、价格类型或币种变化后重新适配。评分上下限紧贴实际数据并留出少量余量，刻度步长随区间调整；价格按当前最小、最大成本选择对数区间，免费模型使用相对于最小正价格的平滑对数偏移以保留零值。

不剔除离群型号，不用位移避免重叠；同价格同评分继续合并标记并显示数量。精确价格与评分仍可在模型详情读取。区间不受重复型号数量影响。

回归覆盖窄价格/评分区间、空集合、免费模型、相同值、极小/极大有限值和坐标单调性。1024px 合成数据浏览器检查了全模型与 GLM 搜索，GLM 评分轴自动缩到 67.2–77.6，模型在图内且页面无横向溢出。

类型检查、生产构建、cargo check、7/7 纯逻辑检查、天梯坐标及组件渲染回归通过。浏览器还核对了输入价格与美元切换后重新适配。Windows 安装包版本、WebView2Loader.dll 哈希及隔离配置解包启动 8 秒通过，证据保存于 src-tauri/target/qa-1301/evidence.json；实际覆盖升级未验证。
