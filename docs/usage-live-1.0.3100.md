# Quota 1.0.3100

本轮重构我的使用、消费历史、输出速度与贴边悬浮窗。主界面保留数字、筛选和操作，统计解释移入悬停或折叠说明；模型天梯、六维对比和实际 Token 单价继续保留。

## 使用变化

- 我的使用提供统计、消费历史、实际 Token 单价三个视图，支持月份、近 7 天、近 90 天、今年、全部及自定义日期，按厂商和原币筛选。
- 费用 / Token 趋势可按日、周、月查看，模型 / 厂商 / 设备用量可展开，当前统计及明细支持 CSV 导出。
- 消费历史展示完整账期及账户累计消费曲线，充值与消费各自保留变化；编辑已有账期仍执行冲突校验和原子替换。
- 悬浮窗顶部显示模型、任务耗时、已确认输出和本轮已完成响应均速，支持多个任务切换；底部保留今日 / 累计 Token。
- 输出速度页重排主次数字，使用相邻观测点之间的单调曲线和轻量填充，保留时间空档、键盘查看和逐条核对。
- Quota 采用白、淡蓝、深蓝；另四种配色分别调整色彩、边线和圆角。液态玻璃默认关闭，可在设置中开启并保存。
- Windows 悬浮窗扩大至固定 324 × 276 画布，展开时改变命中区域与表面裁切。侧栏布局只调整一次，随后做位移动画，减少图表反复重排。

## 数据边界

费用趋势是完整账期按自然日的分摊参考，不是逐日扣款账单。原币保留，实际 Token 单价仍只使用有费用覆盖的同期用量；我的使用继续排除 Trae。未知费用、首次累计计数和重置后的增量保持空缺，充值不能计作消费。

Codex 本机读取以 1 秒为目标周期。悬浮窗的速度只使用已完成且具有有效计时的响应；可用时从本机日志库只读聚合最近 5 秒的接收片段数量。这个全局信号没有所选模型归属，也不等于 Token 数。没有逐 Token 计数时不伪造实时 tokens/s。

液态玻璃是 Quota 的视觉实现，Windows 悬浮窗可使用 Acrylic；不是 Apple 原生材质。内容区保持清晰，减少动态效果、高对比度与可用的减少透明效果设置提供回退。

- 安装：完成 `D:\Quota` 的 **1.0.3003 → 1.0.3100** 覆盖升级。安装向导实际加载并显示完成页；安装版启动 8 秒检查通过，5 份个人资料文件的升级前后哈希一致。安装器主程序与向导程序哈希相同，WebView2Loader 一致。
