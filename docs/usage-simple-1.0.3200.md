# Quota 1.0.3200

本轮把我的使用整理成更直接的人民币费用流程，重做玻璃显示和输出趋势，保留模型对比、实际单价与运行任务。

## 交互

- 默认本月，上方一行选择月份、时间范围和厂商。总览先展示总支出、使用 Token、实际单价，随后展示趋势和厂商费用。
- 主操作改为「记录支出」：填写厂商、原币实付和费用日期即可。套餐按需展开，已有记录仍有冲突与过期编辑保护。
- 消费记录合并人民币与美元费用，表格统一人民币，保留原币金额。账户累计计数另置于折叠核对区，避免与实付重复相加。
- 自定义日期取消不会改变统计范围；相对日期重新进入时随自然日更新。汇率缺失时总额显示待换算，CSV对应金额留空。
- 速度页默认近7天，使用已有时间桶的折线趋势、模型与设备筛选及逐条记录。去掉大面积填充和实时监听式展示。
- 悬浮窗直接列出正在工作的任务、型号、开始时间和耗时，保留今日/累计 Token，移除本轮速度与片段计数。

## 月均人民币换算

美元按费用所属月份的已公布日USD/CNY算术均值折算；每天仅使用同日ECB CNY/EUR与USD/EUR比值。当前月随着新报价更新，月末后形成整月均值，跨月费用按自然日分配后分别转换。所有费用汇总和实际单价共用对应月的均值。

新增`monthly-average-fx.json`作为公开数据的衍生缓存，记录样本日期、数量与检查时间。旧固定/手动参考文件及同步格式保留，但新视图不会把旧值当作月均值。原币费用、费用覆盖分母和Token账本沿用既有格式。

读取官方历史表得到本月21个已公布样本，独立计算均值为6.6865193285；合成的20 USD与100 CNY应合计233.73元。这是隔离数据校核，不是个人支出或银行结算价格。

来源：[ECB历史表](https://www.ecb.europa.eu/stats/eurofxref/eurofxref-hist.xml)、[发布规则](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html)。

## 玻璃修复

旧实现的玻璃层后面是同色实底，且系统的减少透明度偏好会无声覆盖开关。本版加入真正位于内容后方的淡蓝光层，工作区、卡片与导航使用半透明材质和高光边缘。应用内明确开启时生效，高对比度回退为实底，减少动效仍受尊重；没有修改Windows系统设置。

浏览器验收实际出现了`data-glass=on`但背景被`prefers-reduced-transparency`隐藏的失败，修正后完整流程通过，包括开关保存、明暗主题、背景可见与高对比度回退。

## Codex实时能力核实

官方协议提供文本流与用量更新，当前本机JSONL及遥测Token计数仍在响应完成后提供；文本片段不是Token。只读抽查近期日志元数据与本机传输类型后，本版选择已完成响应趋势，不将字符数、片段数或任务经过时长当作实测速率。详见[核实记录与口径](output-speed.md)。
