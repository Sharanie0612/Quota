# Quota 1.0.1900 贴边用量悬浮窗

本轮基于 PR #11 的 `629f7be`，保留此前界面和小米会话修复；PR #11 已合入主分支，本任务与最新主分支对齐。作为同一待发布 1.0.1900 的功能补充，不再次递增版本。

## 行为

- 独立 `usage-widget` 窗口默认停靠右侧，收起为 22×100 逻辑像素的细条；移入展开为 292×186，移出约 800ms 后收起。收起时缩小原生窗口，避免大块透明区域拦截桌面点击。
- 默认显示今日 Token，点击数字切换累计 Token，收起后保留所选显示方式；完整数字可通过悬停提示和辅助功能标签读取。支持键盘展开、切换和 Escape 收起，展开后恢复数字按钮焦点。
- 复用现有已去重的活动资料库，跟随“我的使用”排除 Trae；按本机自然日汇总全部设备，不新增采集、记录或同步包。缓存和推理不再次累加。每 30 秒及收到活动更新事件时读取，跨午夜自动切换日期；读取失败保留旧数值并标记未更新。
- 设置可关闭、选择左右侧及上中下位置；关闭时暂停悬浮窗读取。`usage-widget.json` 仅存本机偏好。定位采用显示器工作区和实际缩放比例，避免任务栏；首次或设置变更时使用主窗口所在屏幕。
- 主面板关闭到托盘后，悬浮窗继续可用。关闭到托盘关闭时，退出整个应用，避免新增窗口导致进程无法退出。

## 窗口与视觉

取消主窗口的原生阴影边框及右侧内容面板的内描边；在前端资源加载前提供匹配主题的背景，避免默认背景闪黑。透明悬浮窗启动时保持隐藏，等待前端就绪再显示。

账户按钮图标统一为 16px 线性图标，模型入口使用圆角四宫格，官网入口使用简洁方向箭头；放大点击区域，减少按钮底色。启动时显示简短 Logo 入场及过渡，增加数字切换、面板展开和按钮响应动效；遵循系统减少动态效果设置。

悬浮窗只加载本机应用页面，阻止第三方导航，无凭据、外部链接或文件对话框权限；窗口大小命令校验调用窗口，只有主窗口能修改设置。Cookie 和密钥仍只进入系统凭据库。
