# 微信登录与云端设备同步接入条件

本轮尚未接入真实微信登录。用户确认尚未准备微信开放平台应用与云端服务；安装包继续提供共享目录同步，不把它描述为微信账号云同步。

## 需要准备

1. 在 [微信开放平台](https://open.weixin.qq.com/) 准备可用于扫码登录的应用，并取得对应审核与登录权限。AppID 可作为公开配置；AppSecret 必须由服务端管理，不能打入桌面安装包、写入仓库或发到聊天中。应用类型、主体资质及回调要求需在平台申请时确认，当前官方开发文档无法直接读取，没有在本项目中假定审核费用或承诺可通过。
2. HTTPS 服务域名、微信后台允许的回调地址、后端运行环境、数据库与密钥管理。用户设备不需要直接访问数据库。需指定谁运营服务，以及备份、删除与维护策略。
3. 账号绑定规则：同一微信身份绑定多个独立设备 UUID；提供设备解绑、退出登录和删除云端用量。必须有账号隔离、权限校验、请求限流和审计。
4. 明确统计上传授权与隐私说明。仅上传现有事件 ID、设备、来源、模型、日期和用量指标；不上传对话正文、工具参数、服务商凭据、Cookie 或本机 Codex 登录令牌。

## 待实现的接口约定（方案，不是已运行功能）

- 登录发起：后端创建短期会话与随机 state，返回官方授权 URL；校验回调，服务端换取微信身份，再签发 Quota 会话。校验 state、时效及单次消费，避免重放。
- 客户端会话：短期轮询获取登录结果；Quota 会话令牌仅进入 Windows 凭据管理器，绑定固定服务域名。AppSecret 永远留在服务端。
- 设备注册：用户授权后注册设备 UUID，设备名称仅作显示；使用账号身份校验每次读写，不接受客户端传入的任意账号 ID 作为授权依据。
- 用量上传：批次按全局事件 ID 幂等写入，保留累计值转增量及缓存/推理子项规则，不将缓存再次计入总量。
- 用量下载：按账号及游标增量取数，离线队列可重试；失败保留本地记录，账号切换不能混用缓存。

准备好应用与服务域名后，才能继续部署、真机扫码、跨设备同步、过期会话及解绑验收。本轮没有部署服务，也没有生成看似可用的模拟登录入口。
