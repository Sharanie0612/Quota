# 悬浮窗与条件定价 · 1.0.2000

基于已发布的 1.0.1900，新功能展示号与包版本均为 1.0.2000。依赖 PR #14 的桌面与同步修复；本次不改变账单和实际支出。

## 改动

- Windows 悬浮窗保持 292×186 逻辑像素的固定画布，展开/收起只改变原生窗口区域，不重新调整 WebView 大小；收起后仅侧边 22×100 区域接收点击，其他部分不遮挡桌面。背景从窄条连续展开成圆润卡片，文字独立淡入、不缩放。鼠标中途返回立即反向，按表面动画实际完成事件收窄点击区域，420ms 超时仅作事件缺失兜底。保留移开收起、拖动贴边、减少动态效果与窗口身份校验。
- 当前分类有评分但没有官方可比价格的模型显示在独立能力排行中，不使用零价、不把图像/音频按次价格伪装为 Token 价格。其他分类与推理筛选不再被计入缺价数量。汇率缺失时按原币种分图，不漏掉另一币种模型。
- 条件价格独立保存在 `priceOptions`，每档附条件说明，与同次官方成功核实的来源和时间一起保存。旧快照的 `offPeak` 继续读取。抓取失败保留旧核实数据，成功读取后清除不再存在的条件档位。
- 快照保存价格解析版本。升级时旧解析器的当日检查不再阻止重新核实，避免 Haiku 旧错误价格延续 24 小时；仍尊重用户关闭自动更新的设置。
- 修复 Haiku 5.5 长输入行覆盖短输入行的错误，短输入默认使用不超过 100,000 Token 档，超过阈值时整次请求使用长输入档（缓存读写也计入阈值）。
- OpenAI：分别读取 Standard、Batch、Flex 的官方表，短输入与 >272K 长输入独立，不能凭默认价直接乘五折。
- Anthropic：独立读取 Batch 输入/输出表，与标准行交叉核对官方五折声明；只在官网明确允许叠加时计算对应缓存读写折扣。
- DeepSeek：高峰、闲时分别读取；仅在时段与五折声明均匹配时展示闲时档，不用本地时钟猜测中国法定节假日，也不混入第三方转售价格。
- Google：分别解析 Standard、Batch、Flex，按官方连续起止日期选择当前生效价。修复只识别固定截止日期导致 Gemini 4 Argon 缺价；保留临时优惠期限，不把临时活动称为永久价格。
- 小米：独立读取国内实时/批量表格，不给未列入批量表的型号套用折扣。
- Meta：适配当前逐模型 Standard/Contributor 表头，精确匹配官方模型 ID；不将有独立端点与数据使用条件的 Contributor 价格自动套入 Standard 模型。

价格图表示所选计费场景下的单位价格对比，默认输入+输出为各一百万 Token，不代表实际账单。不同场景不能自动叠加；未核实所选档位的模型仅保留评分。闲时模式中没有已核实闲时档位的模型使用标准价并明确标注。模型详情可查看缓存命中以及条件档位。
