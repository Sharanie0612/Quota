# 悬浮窗与 Trae 分类修复（1.0.1900）

2026-10-16，基于已合并 PR #12 的 main（5ffaa3e）。最新公开发布仍为 1.0.1800，本轮继续修正待发布 1.0.1900，不重复递增版本。

## 行为

- 悬浮窗数字用中文万、亿单位，并以较小字号区分单位；完整数字继续放在提示及辅助功能标签中。
- 保持面板与贴边入口挂载，展开先调整原生窗口再播放位移/透明度过渡；收起先播放 260ms 退场，再缩小原生窗口。移出延迟 800ms，可中途移回取消收起，遵循减少动态效果设置。
- Token 活动的供应商汇总恢复 Trae，另有 Trae 提供 / API 接入 Trae / 未鉴别通道筛选。旧记录缺少通道时只归未鉴别，不猜来源。
- 厂商及普通模型筛选只统计非 Trae 来源，Trae 供应商及通道只统计 Trae 来源。同名模型不再让两个来源混算。全部用量仍保留所有记录。
- 模型选项和模型明细不列 Trae 的内部模型名；缓存面板将 Trae 记录按通道汇总，保留总输入及缓存命中量。选择 Trae 自动打开通道明细。
- 不修改原始指标、去重 ID 或同步协议，不重采集或重复记账。“我的使用”与悬浮窗仍按既有要求排除 Trae。
