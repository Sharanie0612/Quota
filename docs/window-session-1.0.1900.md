## 一体化主窗口

主窗口关闭系统装饰，移除原本固定、带底色和分隔线的页面顶部横条。页面标题、账户刷新与添加操作进入内容滚动区；侧栏、配色、毛玻璃及圆角沿用现有设计系统。右上角提供最小化、最大化/还原、关闭按钮；顶部留白与品牌区域可拖动，双击拖动区可最大化。关闭调用正常窗口关闭事件，仍遵守“关闭到托盘”设置。

窗口操作权限只授予 `main`，小米官网窗口及恢复窗口仍无 Quota IPC 权限。参考：[Tauri 自定义窗口](https://v2.tauri.app/learn/window-customization/)。本轮目标 Windows；macOS 原生窗口体验未实测。

## 小米过期会话续接

核对 2026-10-15 [官方控制台](https://platform.xiaomimimo.com/)的公开前端资源后确认：登录按钮进入 `/api/v1/genLoginUrl?currentPath=...`；首页查询用户资料使用 `skipAuthRedirect`。旧恢复流程只打开首页，短期 API Cookie 过期时不会主动启动 SSO，容易将仍可续接的会话误报为必须重新登录。

恢复改为在隔离、无 Quota IPC 权限的 WebView 中进入固定官方 SSO 入口，注入凭据库中仍有效的官方 Cookie。官网完成跳转、独立验证余额接口认证成功后，先保存更新后的完整会话，再查询套餐；无订阅或套餐接口失败不会丢失已续接登录。失败重试间隔由 30 分钟降至 1 分钟，成功后清除失败记录；网络超时保留已保存的登录信息。

Cookie 持久化将收到的相对 `Max-Age` 固定为绝对 `Expires`，重启不重新延长有效期；规范化域名大小写和默认路径，同键替换、过期删除，保留官方其他路径的轮换 Cookie 供 SSO 使用。旧 schema 1 仍可读取，新写入格式仍为 schema 1；旧文件没有记录相对 Cookie 的接收时刻，无法重建过去的准确到期时刻，恢复后以官网验证结果及新返回的有效期为准。按量与订阅卡通过同一个凭据库会话引用更新，即使旧短期 Cookie 已清空，也可一起续接；其他登录不受影响。

Cookie、SSO 及轮换后的会话仍只保存到操作系统凭据库，不写配置、日志、云同步包，不进入渲染进程。软件不延长小米服务端的会话有效期；官网 SSO 本身已失效或要求扫码/验证时，仍需用户在官方窗口重新连接。
